

# To-Do App

## 1. Project Overview
A responsive To-Do application built with React.js that helps users organise their daily tasks. It was developed as part of the Web Development Week 04 Mini Project. The user interface was designed mainly using Figma, with a focus on a clean, aesthetic and user-friendly layout.

## 2. Features Implemented
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Edit existing tasks
- Display task status (Completed / Pending)
- Task filtering (All, Completed, Pending)
- Add due dates to tasks
- Local storage to retain tasks after page refresh
- Responsive design for mobile and desktop

## 3. Technologies Used
- Figma (main tool used for UI/UX design)
- React.js (Vite)
- JavaScript (ES6+)
- HTML5 and CSS3
- Browser localStorage

## 4. Setup Instructions
1. Clone the repository:
   `git clone <[your-repo-link](https://github.com/bhukyatejanayak07-bot/Projects-Web-Technology
)>`
2. Go to the project folder:
   `cd to-do-app`
3. Install dependencies:
   `npm install`
4. Start the development server:
   `npm run dev`
5. Open the local link shown in the terminal (usually http://localhost:5173).
